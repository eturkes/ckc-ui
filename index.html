How IR improves this pipeline

Short version

Both M2 routes now finish at SMT-LIB. Direct asks the model to write SMT-LIB; IR asks the model for one bounded pair JSON object, bridges those rows into route_rule_ir.v0, then compiles that IR deterministically to SMT-LIB.

Both routes use lexical_cue_v1 (cue hash 92c20ba92a353c0e...5ecb68). The current lift measurement is about moving formal-target burden away from the weak model while keeping the final target comparable.

1. Same input Japanese fixture spans become shared source cues before either route runs.
2. Direct route route.direct_smt asks the model to write a whole executable SMT-LIB target.
3. IR route route.single_ir asks for one pair JSON object; this harness emits a per-row SMT-LIB target from the admitted route IR.
