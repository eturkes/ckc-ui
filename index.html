Route Ranking

Routes are ranked by accuracy: how often the generated target reached the expected verdict on the current trial rows.

Success rank Complexity rank Route Accuracy Route description
1 4 route.ir_hop_chain 3/4 Breaks the translation into several small structured JSON steps before compiling the final target.
2 2 route.single_ir 1/4 Asks the model for one structured JSON draft, then compiles that draft into the final target.
2 3 route.stacked_ir 1/4 Asks the model for a short stack of structured drafts, from source summary to rule-like output.
2 5 route.ckc_layered 1/4 Uses an in-development project-native IR to turn sources into normalized statements and rules.
2 6 route.ckc_repair 1/4 Extends the project-native IR route with a self-repair pass that feeds failed structure checks back so the model can revise its draft.
3 1 route.direct_smt 0/4 Asks the model to write the final formal solver target directly in one step.

ルートランキング

ルートは精度で順位付けしています。現在の試行行で、生成されたターゲットが期待された判定に到達した頻度です。

成功順位 複雑度順位 ルート 精度 ルート説明
1 4 route.ir_hop_chain 3/4 翻訳を複数の小さな構造化 JSON ステップに分けてから、最終ターゲットへコンパイルします。
2 2 route.single_ir 1/4 モデルに 1 つの構造化 JSON ドラフトを作らせ、そのドラフトを最終ターゲットへコンパイルします。
2 3 route.stacked_ir 1/4 モデルに短い構造化ドラフトの積み重ねを作らせ、ソース要約からルールに近い出力へ進めます。
2 5 route.ckc_layered 1/4 開発中のプロジェクト固有 IR を使い、ソースを正規化されたステートメントとルールに変換します。
2 6 route.ckc_repair 1/4 プロジェクト固有 IR ルートに自己修復パスを追加し、構造チェックに失敗した箇所をモデルへ戻して下書きを修正させます。
3 1 route.direct_smt 0/4 モデルに最終的な形式ソルバー用ターゲットを 1 ステップで直接書かせます。

ルートのパイプライン

各ルートは同じ作業を異なる構成で行います。モデルが中間ドラフトを生成する回数と、固定のコンパイラが最後のドラフトをソルバーターゲットに変換する位置が異なります。右側の比率は上のランキングと同じ精度です。
