What the experiments are trying to prove

Each stage is a vertical slice ending in replayable artifacts, not a clinical product claim.

research evidence
ReuseLayered reusable IR beats direct per-document formalization on reuse, compactness, convergence, and trace quality.
LiftIR configuration changes how well weak models produce admitted symbolic artifacts.
AmortizationAdmitted mappings remove model calls from fresh-document apply paths while retaining coverage.
AutoresearchA bounded loop can improve routes and mappings against a locked evaluator.

V3b amortize

Build once, apply many

Build admitted mappings on fixture set A, then apply them to fresh set B with zero runtime model calls.

  • inputsharing fixture sets A and B
  • methodadmitted mapping layer, deterministic apply
  • proofcoverage, accuracy, mapping size, zero apply calls
ckc run --experiment exp.v3_amortize
V4 loop

Autoresearch loop

Bounded propose, patch, run, score, classify, promote/reject, replay, and ledger cycle against an immutable evaluator.

  • inputlocked evaluator plus declared editable surfaces
  • methoddriver-portable loop with budgets and ledger
  • proofvalid scored attempts, replayed promotions
